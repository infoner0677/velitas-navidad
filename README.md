# 🕯️ Velitas de los Deseos · Catálogo de Navidad

Catálogo web interactivo de cajas de velitas decoradas para la Noche de las Velitas y la Navidad.

**Ver el catálogo:** https://infoner0677.github.io/velitas-navidad/

## Cómo personalizarlo
Abre `index.html` y busca la sección `CONFIGURACIÓN` dentro del `<script>`:

- `WHATSAPP`: los números que reciben los pedidos (con indicativo 57, sin + ni espacios). Hoy: 310 798 9219 y 310 239 6842.
- `TIERS`: precios de las cajas **sencillas** y **con relieve** para 1, 2 y 3 cajas (promociones). El pedido calcula solo el mejor precio y los portavelas de regalo (1 por cada 3 cajas).
- En la lista `PRODUCTS`, cada caja tiene `tier: "sencilla"` o `tier: "relieve"`.
- Las fotos están en la carpeta `img/`.
